# Data Schema

All data lives in `data/` as JSON. Units are fixed: **inches, pounds, USD, watts,
amps**; capacity carries its own unit. Any field that isn't sourced is `null`
(never guessed) and is picked up as a queue task.

---

## 1. `parts-db.json` — Parts DB (`parts_db@2`)

The canonical component catalog. Generated by `scripts/build_parts_db.py`.

```jsonc
{
  "schema": "parts_db@2 (Van Parts DB / Spec §5.2, extended)",
  "generated": "YYYY-MM-DD",
  "units": { "length": "in", "weight": "lb", "cost": "usd", "power": "W", "current": "A" },
  "count": 33,
  "systems": ["appliance","cabinetry","electrical","hvac","plumbing","tank"],
  "components": [ /* Component[] */ ]
}
```

### Component

```jsonc
{
  "id": "el-bb-200",                 // stable slug, unique
  "name": "LiFePO4 battery bank (2×100Ah)",
  "system": "electrical",            // electrical|plumbing|hvac|tank|appliance|cabinetry|roof|material
  "category": "Battery",             // sub-type, drives the planner icon
  "brand": "Battle Born",
  "model": "2× BB10012",

  "dims": { "l": 27, "w": 13, "h": 9 },   // inches; any axis may be null
  "weightLb": 62,                          // null when unknown
  "costUsd": 1750,                         // null when unknown

  "electrical": {                          // null for non-powered parts
    "role": "source",                      // source|load|converter|distribution|monitor
    "voltage": "12V",                      // 12V|24V|48V|120V|240V|N/A
    "contAmps": 200, "peakAmps": 400,
    "surgeWatts": null, "idleWatts": null, "dailyAh": null,
    "recommendedFuseA": 125, "fuseType": "Class-T",
    "minWireAwg": "2 AWG",
    "comms": "BT", "switchedBy": "none", "terminals": "M8 ring",
    "inverterW": null, "runWatts": null
  },

  "plumbing": {                            // null for non-plumbing parts
    "flowGpm": null, "connectionSizeIn": 0.5, "powered": false,
    "valveType": null, "tankGal": 25, "fluid": "fresh"   // fresh|gray|waste|hot_water
  },

  "capacity": { "value": 200, "unit": "Ah", "kind": "Battery capacity" }, // or null

  "mounting": { "surface": "floor", "fasteners": "strap", "clearanceIn": 2,
                "orientation": "upright", "notes": "Class-T fuse within 7\" ..." },

  "sources": [ { "label": "Battle Born BB10012 spec", "url": "https://..." } ],
  "confidence": "manufacturer",            // verified|manufacturer|estimated|unverified
  "verified": true,                        // human sign-off
  "tags": ["lithium","house bank"],
  "updatedAt": "YYYY-MM-DD",

  // computed by the generator:
  "missing": [],                           // required fields still null
  "placeable": true,                       // all three dims present
  "needsReview": false                     // !verified || estimated/unverified || missing
}
```

**Required fields** (drive `missing` / sourcing tasks): always `dims.l/w/h`,
`weightLb`, `costUsd`; if `electrical` present: `voltage`, `contAmps`,
`minWireAwg`, `recommendedFuseA` (role-aware); if `plumbing` present: `fluid`.

## Confidence levels (shared vocabulary)

| Level | Meaning |
|---|---|
| `verified` | a human checked it against the datasheet |
| `manufacturer` | from the maker's published figures, not yet human-checked |
| `estimated` | typical/approximate; confirm before building |
| `unverified` | placeholder from an unconfirmed source |

The TypeScript mirror of the component shape (an alternative typed accessor)
lives in `app/van-parts-db/src/types.ts`.
